What it does

  • Opens PNG, JPEG, WebP, TIFF, BMP, ICO, QOI, TGA, and PNM files
  • Crop, rotate, flip, resize, and stitch
  • Pen, highlighter, shapes, arrows, text, and stickers
  • Measure in pixels or real units
  • Undo and redo for everything
  • A file size estimate before you save
  • Keeps photo details, or removes the location
  • A command palette and a shortcut for every command
  • Light and dark themes
  • Windows 10 and 11 (Arm and x64), and macOS

What it doesn't do

  • No account, no ads, no data collection
  • No internet connection
